# ڈاکٹر کے بل میں دوائی کی تبدیلی — الگ فائل

یہ myherbalpk.com والا «🔁 ڈاکٹر کے بل میں دوائی کی تبدیلی» حصہ ہے، الگ کر کے، تاکہ کسی اور ویب سائٹ پر لگایا جا سکے۔
myherbalpk.com پر یہ حصہ پہلے کی طرح موجود ہے۔

## فائلیں

| فائل | کام |
|---|---|
| `index.html` | پورا صفحہ: تصویر کھینچیں/گیلری، دوائیں چیک کریں، ٹک کر کے برانڈ چننا، فوائد، ملک، نئی لسٹ، کاپی/واٹس ایپ |
| `api/rx-swap.js` | سرور والا حصہ (Vercel): تصویریں OpenAI کو دے کر دوائیں پڑھواتا ہے |

## نئی ویب سائٹ پر لگانا (Vercel)

1. دونوں فائلیں نئی ویب سائٹ کے ریپو میں ڈالیں:
   - `api/rx-swap.js` → ریپو کے `api/` فولڈر میں
   - `index.html` → جہاں یہ صفحہ چاہیے، مثلاً `dawai-tabdeeli.html` یا `index.html`
2. Vercel میں اس ویب سائٹ کے پروجیکٹ کی **Settings → Environment Variables** میں `OPENAI_API_KEY` ڈالیں، پھر Redeploy کریں۔
3. بس۔ صفحہ کھول کر تصویر ڈالیں اور «دوائیں چیک کریں» دبائیں۔

## کسی موجودہ صفحے کے اندر لگانا

`index.html` میں سے تین چیزیں اپنے صفحے میں کاپی کریں:
- `<style>` والا حصہ (رنگ اور ڈیزائن)
- `<section id="page-rxswap"> ... </section>` (بٹن اور نتیجہ)
- آخر والا `<script>` (سارا کوڈ اور دواؤں/کمپنیوں کا ڈیٹا)

## سرور کسی اور جگہ ہو

اگر `api/rx-swap.js` کسی دوسری ویب سائٹ پر چل رہا ہو تو `index.html` میں یہ لائن بدلیں:

```js
const RX_API = '/api/rx-swap';
```

اور وہاں اس سرور کا پورا پتہ لکھیں، مثلاً `https://example.com/api/rx-swap`۔
(دوسری ویب سائٹ سے بلانے کے لیے اس سرور پر CORS کی اجازت بھی چاہیے ہوگی۔)

## نوٹ

- Vercel کے مفت پلان میں زیادہ سے زیادہ 12 سرور فائلیں (api) بنتی ہیں۔ اگر نئی سائٹ میں پہلے ہی 12 ہوں تو `handleRx` کو کسی موجودہ فائل کے اندر ڈالیں، جیسا myherbalpk.com میں `api/book-item-info.js` کے اندر ہے۔
- تصویر AI پڑھتا ہے، غلطی ممکن ہے۔ صفحے پر یاد دہانی موجود ہے کہ پیکٹ پر اصل دوا (generic) اور طاقت ڈاکٹر کے لکھے سے ملائیں۔
